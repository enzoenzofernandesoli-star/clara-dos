# Clara dos Anjos — resumo de estudo

Site de estudo do romance *Clara dos Anjos*, de Lima Barreto: resumo capítulo por capítulo com análise, personagens, temas, revisão, práticas interativas e mapa mental.

- `index.html` — resumo
- `mapa.html` — mapa mental interativo
- `img/` — ilustrações
- `_fonte/` — fontes para regerar (`python3 _fonte/gen_svg.py && python3 _fonte/build.py`)

Site estático: publique a raiz do repositório na Vercel (sem build).
